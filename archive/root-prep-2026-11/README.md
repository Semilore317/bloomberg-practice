# Archived root-level preparation docs

These files were the repository-wide preparation workflow before migration to
exercise-level preparation. They are preserved here for history. They are no longer
referenced by the active documentation.

## What replaced them

Each exercise now contains:

- `AGENTS.md` — the self-contained assistant contract.
- `prep/WORKFLOW.md` — the A–F investigation workflow, triage rubric, and findings log.
- `prep/AI_PROMPTS.md` — phase-gated prompts.

## Mapping

| Archived file | Replacement |
| --- | --- |
| `docs/PREP_WORKFLOW.md` | `prep/WORKFLOW.md` in each exercise |
| `docs/AI_PROMPTS.md` | `prep/AI_PROMPTS.md` in each exercise |
| `docs/SESSION_TEMPLATE.md` | Findings log embedded in `prep/WORKFLOW.md` |
| `docs/SEVERITY_RUBRIC.md` | Triage rubric embedded in `prep/WORKFLOW.md` |
| `drills/open-audit.md` | Open-ended mode in `prep/WORKFLOW.md` |
| `drills/performance-review.md` | Optimisation phase in `prep/WORKFLOW.md` |

The exercise-level files are intentionally generic: they do not name rounds, languages,
or other exercises, so any exercise can be opened on its own.
